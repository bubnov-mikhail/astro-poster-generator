# Небо над Москвой · 2027

Веб-проект и печатный плакат: **астрономический календарь наблюдателя** на 2027 год для Москвы.

## О проекте

Это одностраничная инфографика для печати (A4) и просмотра в браузере. Она показывает, **когда с широты Москвы** в 2027 году удобно наблюдать планеты Солнечной системы и как меняются фазы Луны в течение года.

Идея — один взгляд на год: круговая диаграмма связывает календарь, Луну и окна видимости планет, а таблица внизу даёт даты, ключевые события и короткие заметки наблюдателя.

**Для кого:** любители астрономии, школы, клубы, домашняя печать плаката на стену.

**Что можно сделать с проектом:**
- открыть макет в браузере и листать как справочник на год;
- распечатать A4 (или сохранить PDF) без отдельного дизайн-редактора;
- скачать готовый растр высокого разрешения для типографии или домашней печати.

## Что на плакате

- **Круговая диаграмма** (от центра к краю): художественный центр Солнечной системы → кольца видимости Меркурия–Сатурна (заливка текстурой планеты, разрывы там, где планета не видна) → фазы Луны по точным датам → названия месяцев.
- **Фон:** вечернее небо, зарево и силуэт Москвы.
- **Таблица:** периоды наблюдения семи планет (включая Уран и Нептун), ключевые события и заметки.

Данные: фазы Луны — календарные эфемериды 2027; конфигурации планет — ИАА РАН / Астронет; окна видимости — для широты Москвы (~55,8° N).

## Запуск

```bash
git clone https://github.com/bubnov-mikhail/astro-poster-generator.git
cd astro-poster-generator
node scripts/decode-lock.mjs      # восстановить package-lock.json
node scripts/decode-assets.mjs    # распаковать JPG из public/art/_pack
npm install
npm run dev
```

Откройте адрес из терминала (по умолчанию порт **3847**). Кнопка «Печать / PDF» отправляет макет на принтер или в PDF.

## Печать

- Готовый файл **A4 · 800 dpi** собирается скриптом:

```bash
npm run dev   # в другом терминале, на :3847
node scripts/export-a4-800dpi.mjs
```

Результат: `nebo-moskva-2027-A4-800dpi.png` (6614×9354 px ≈ 210×297 мм при 800 dpi).

- Из браузера: «Печать / PDF», масштаб 100% / «фактический размер».
- Формат **10×15**: уменьшите по ширине листа или обрежьте по центру композиции.

Рекомендуется цветная печать, бумага от 160 г/м².
